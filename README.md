# smart-pitch website

One-page company website for smart-pitch, hosted on GitHub Pages.

## Things to fill in (all in `index.html`)

| What | Where to look |
|---|---|
| YouTube video | Replace `YOUR_VIDEO_ID` (the part after `watch?v=` in your YouTube link) |
| Contact form → your email | Get a free key at https://web3forms.com and replace `YOUR_ACCESS_KEY` |
| Team photos | Upload pictures to an `images/` folder and swap `Photo 1/2/3` for `<img src="images/photo1.jpg" alt="...">` |
| Text, testimonials, company details | Edit the text directly. Search for "Client name", "Venue name", "Street address" |

## Custom domain later
Settings → Pages → Custom domain, then add the DNS records GitHub shows you at your domain registrar.
